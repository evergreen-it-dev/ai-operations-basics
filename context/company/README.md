# Компанія

Сюди кладуть факти, на які агент має спиратися: команда, процеси, що за продукт.

Код і доки продукту сюди не класти. Репозиторій продукту — git submodule у `context/products/<product-name>/`.

Порожньо навмисно. Не вигадувати людей і клієнтів, доки їх тут немає.

- `personas.md` — хто типові адресати листів
- `teammates.md` — хто в команді, ролі й зони відповідальності. Кожен веде свій рядок

Особисте з `workspace/` сюди переносять за правилом shared-context-merge: на запит «перенеси мої напрацювання в спільну репу». Свій рядок у teammates оновлюється, факти про компанію — після згоди.
