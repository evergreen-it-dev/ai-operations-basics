# Дизайн

Локальні знімки макетів Figma. Повна відповідь MCP сюди не кладеться.

- `catalog.yaml` — які макети є: ім’я, slug, file key, URL, сторінки.
- `<figma-name>/design.md` — стисла версія одного макета: екрани і компоненти з параметрами.
- `<slug>/DESIGN.md` — дизайн-система у форматі [DESIGN.md](https://designmd.ai/what-is-design-md): кольори, типографіка, відступи, компоненти, тіні, правила. Скіл `.cursor/skills/design-md/SKILL.md`.

`<figma-name>` — латиниця, kebab-case.

Спочатку читати ці файли. Оновлення — через Figma MCP або REST API, не через браузер. Як саме — у `.cursor/skills/figma/SKILL.md`.
