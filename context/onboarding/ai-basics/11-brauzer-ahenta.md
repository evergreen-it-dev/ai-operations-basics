# Браузер в агенті: простий старт автоматизації

Браузер агента — **найпростіший спосіб** почати автоматизацію, коли ще немає API чи MCP. Агент відкриває той самий сайт, що й ви: клікає, читає екран, заповнює поля, знімає результат. Це як показати новому співробітнику «натискай сюди» — тільки співробітник віртуальний.

Потрібен режим із браузером: Agent Window / Cowork / GPT Work (назви різняться). Smoke-test: «відкрий google.com у браузері агента».

## Детальніше

### Навіщо це взагалі
- швидко перевірити ідею end-to-end без розробки інтеграції;
- пройти рідкісний або «одноразовий» сценарій на сайті без API;
- розвідати UI: які кнопки, які поля, що ламається;
- тимчасовий місток, поки не з’явиться стабільний API/MCP.

Саме так багато людей і починають AI-зацію процесу: спочатку браузер «як руками», потім skill, потім підйом на API.

### Як користуватися
Логін інколи зробіть **вручну** в тій самій вкладці; паролі в чат не пишіть (краще вже залогінений профіль / сесія). Агент клікає й читає UI; ваш клік теж може стати підказкою («що це за кнопка?»).

Корисний прийом: ви клікаєте раз → питаєте «що ти бачиш» → далі він повторює шлях сам у межах skill.

### Обмеження
Повільно; залежить від логіну, ОС і змін дизайну екрана. Редизайн сайту легко «ламає» сценарій. Тому браузер — чудовий **старт і discovery**, але не ідеал для щоденного продакшен-ритму: щойно сценарій стабільний — піднімайтесь драбиною до API/MCP (див. розділ про API проти браузера).
