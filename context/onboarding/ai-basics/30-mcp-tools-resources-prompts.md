# MCP: Tools, Resources, Prompts і правила

У MCP зазвичай три «полиці»:

**Tools** — дії: «зроби запит», «створи тікет», «витягни звіт». Пакуйте сюди часті операції. Не підключайте всі інструменти одразу: кожен опис їсть місце в контекстному вікні.

**Resources** — матеріали для читання (файли, витяги) без простині в чаті. Модель отримує доступ до артефакту, а не до кілометрів JSON у повідомленні.

**Prompts** — готові шаблони запитів на боці MCP, щоб сценарій не жив лише «в голові» або в разовому чаті.

Окремо — **правила біля tool**: коли (не) викликати, що зберігати, який формат віддавати, що писати у файл vs у чат. Без цього агент тикає тулзи хаотично; разовий промпт у чаті це майже не лікує.

## Детальніше

### Порядок підключення
1. 1–3 критичні tools під вашу роль.
2. Resources для великих або сирих артефактів.
3. Prompts для повторюваних сценаріїв.
4. Правила виклику — у описі tool / MCP, не лише в голові.

### Менше = стабільніше
Краще мало tools із чіткими правилами, ніж зоопарк «на всяк випадок». Кожен зайвий tool — зайвий шум і ризик дивної дії.
