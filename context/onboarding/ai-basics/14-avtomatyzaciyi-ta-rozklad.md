# Автоматизації та розклад

Спочатку **2–3 стабільні ручні** прогони skill — потім cron / automation. Scheduled run часто йде іншим контекстом (інший юзер, інший шлях до ключів).

## Детальніше

### Чеклист перед cron
- ідемпотентність (повторний запуск не дублює хаос);
- алерт на fail (хтось побачить);
- секрети доступні scheduler;
- сухий прогін у той самий час доби, що й прод;
- зрозуміло, *куди* пишеться результат.
