# Своя бібліотека промптів і Projects

Не пишіть важливі запити «з голови» щоразу. Зберігайте **свою бібліотеку** перевірених промптів і коротких інструкцій — папку з файлами, яку ви самі наповнюєте й оновлюєте.

Підключіть її до **Project** (ChatGPT, Claude тощо) або до workspace в Cursor: тоді модель щоразу бачить ваш домен, а не порожній чат. Якість стрибає саме від постійного контексту, не від «магічного» формулювання одного повідомлення.

## Детальніше

### Навіщо своя бібліотека
- фіксуєте те, що вже спрацювало (тон, структура, заборони, формат відповіді);
- нові люди / новий чат стартують не з нуля;
- менше «випадкових» промптів і роз’їзду стилю в команді.

Можна орієнтуватись на готові внутрішні збірки (якщо є в компанії) — але **мета** та сама: мати *свою* полицю, а не покладатись на пам’ять.

### Що класти на полицю
- 5–20 найкращих промптів під вашу роль (PDF або markdown);
- короткі гайди «як ми робимо X»;
- словник термінів / продукту;
- приклади хорошого й поганого результату.

### Чеклист Project (ChatGPT / Claude)
1. Створіть Project під роль або напрям.
2. Завантажте туди файли з бібліотеки (PDF + markdown).
3. Коротко опишіть у Project: хто ви, який продукт / команда.
4. Оновлюйте файли, коли змінюється реальність (процес, тариф, назви).

### У Cursor / подібних агентах
Той самий сенс: репозиторій + правила + skills + підключення. Project у чаті ≈ постійний контекст поруч із задачею.
