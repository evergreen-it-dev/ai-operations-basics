# Дерево коротких гайдів

Один «товстий» документ агент або не дочитає, або з’їсть вікно. Краще короткий **overview-маршрутизатор**, який веде в маленькі гайди по конкретних кейсах. Під задачу підвантажується лише потрібне.

```
overview.md
guides/
  invoice-flow.md
  birthday-reminders.md
```

## Детальніше

Overview тримає посилання й «коли який гайд». Кожен гайд — одна задача, один критерій готово. Це той самий принцип, що й окремі skills замість одного гігантського промпта.
