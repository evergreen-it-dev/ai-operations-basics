# Шлях: ручна задача → Skill → розклад

1. Зробіть раз з агентом.
2. Оформіть skill.
3. 2–3 стабільні прогони + покращення.
4. API/MCP замість браузера, де можна.
5. Розклад після стабільності.
6. Push у спільний репо за потреби.

## Детальніше

### Критерій «готово»
Колега запускає skill за вашим коротким абзацом без вас на дзвінку.

### Типова помилка
Стрибок одразу в cron після одного «щасливого» прогону. Спочатку стабільність вручну.
