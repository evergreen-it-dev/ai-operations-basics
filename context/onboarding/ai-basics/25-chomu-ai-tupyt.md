# Чому AI «тупить»

Три причини — як у людини з поганою постановкою задачі:

1. **поганий промпт**;
2. **погано обрана модель** (у т.ч. зайвий Thinking або безглуздий Fast);
3. **перевантажений / брудний контекст**.

AI підвищує рівень вашого мислення: ви піднімаєтесь до архітектора / ліда, працюєте з абстракціями. І це найкращий учитель — може просто пояснити, де ви помилилися.

## Детальніше

| Симптом | Дія |
|---------|-----|
| Мимо теми | Переписати мету **одним** реченням |
| Вода / ускладнення | Зняти Thinking; звузити промпт |
| Дорогий «швидкий» рахунок | **Вимкнути Fast** (часто ×1.5–×6) |
| Забув початок чату | Summary + новий чат; менше сирого логу |
| Вигадки про продукт | Додати файли / Project / Rules / MCP |
| Іноді A, іноді B | Прибрати суперечливі rules (ненасичений контекст) |

Технологія не робить вас «тупішими» — вона вимагає кращої постановки задач.
