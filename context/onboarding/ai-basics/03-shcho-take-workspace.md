# Що таке Workspace (і аналоги в GPT / Claude)

**Workspace** — це «робочий стіл» для AI: місце, де лежать ваші файли, правила «як себе вести» і (де можливо) підключення до систем. Агент або чат бачить не порожнє вікно, а *ваш* світ.

Назви різні, ідея одна:

| Де працюєте | «Стіл» зі знаннями | Режим, що *діє* (не лише відповідає) |
|-------------|-------------------|--------------------------------------|
| Cursor / IDE-агенти | Workspace (= часто git-репо) | Agent Window |
| ChatGPT | **Project** + файли + інструкції | **ChatGPT Work** / agent (браузер, дії) |
| Claude | **Project** + файли + інструкції | **Cowork** (і подібні agent-режими) |

Різні напрямки зручно тримати **окремо**: operations, hiring, особисте. Тоді інструкції не змішуються, а відповіді лишаються в темі.

Без звички *наповнювати і запускати* workspace «база від когось» швидко мертвіє: файли є, а роботи — немає.

## Детальніше

### Що всередині (універсально)
- файли знань і прикладів (гайди, PDF, таблиці, промпти);
- постійні інструкції («хто я», «який продукт», «не вигадуй цифри», формат відповіді);
- повторювані сценарії (skills / saved prompts / custom GPT);
- доступи до систем (конектори, MCP, API) — секрети не в спільному git без захисту;
- інколи автоматизації або невеликі UI поверх цього.

Спочатку спитайте в чаті проєкту: «які файли й інструкції ти бачиш?» → «зроби X за ними». Розуміння — від запуску, не від екскурсії по меню.

### ChatGPT: Project + Work

**Project** — це ваш постійний контекст у ChatGPT:

1. Створіть Project під роль або напрям (не один «на все життя»).
2. У налаштуваннях Project коротко опишіть: хто ви, який продукт/команда, які правила відповіді.
3. Завантажте файли з бібліотеки промптів і гайдів (PDF + markdown — обидва формати корисні).
4. Далі **відкривайте чати саме всередині цього Project**, а не в загальному Idle-чаті — інакше модель знову «гола».

Що класти в Project:

- 5–20 перевірених промптів і шаблонів;
- словник продукту / процесів;
- приклади хорошого результату;
- короткі «як ми робимо X».

Оновлюйте файли, коли змінюється реальність (тариф, назви, процес) — застарілий Project гірший за порожній.

**ChatGPT Work** (agent / «робота з діями») — коли потрібно не лише текст, а *зробити*: відкрити сайт, пройти сценарій у браузері, зібрати дані з екрана. Паралель до Agent Window в Cursor.

- Для питань і чернеток — звичайний чат **у Project** (контекст уже підключений).
- Для кліків, логіну на сайті, «зроби як руками в UI» — **Work / agent**.
- Паролі в чат не пишіть: залогіньтесь самі або тримайте сесію; секрети — у менеджері паролів / локальних ключах.

Типовий старт у ChatGPT: Project з гайдами → задача в чаті Project → якщо потрібні дії в браузері — Work на тій самій задачі.

### Claude: Project + Cowork

**Project** у Claude — той самий сенс, що в ChatGPT:

1. Project під роль / напрям.
2. Інструкції проєкту: роль, продукт, заборони, формат.
3. Файли знань (документи, гайди, промпти).
4. Робота *всередині* Project, щоб кожен новий тред наслідував контекст.

Корисно розділяти Projects так само, як workspace: окремо ops, окремо hiring — менше плутанини в інструкціях.

**Cowork** — режим, де Claude не лише відповідає, а допомагає *виконувати* роботу з артефактами / діями (аналог Agent Window / ChatGPT Work). Використовуйте, коли треба пройти сценарій, попрацювати з файлами чи UI-кроками, а не лише отримати абзац тексту.

- Планування й формулювання — чат у Project.
- Виконання з діями — Cowork (або інший agent-режим клієнта, якщо саме він у вас увімкнений).
- Ті самі правила безпеки: не світити секрети в діалозі; чутливі кроки — з людиною в контурі.

Типовий старт у Claude: Project з бібліотекою → питання «що ти бачиш у проєкті?» → задача → за потреби Cowork для дій.

---

### Cursor (коротко, для порівняння)
Репозиторій + `.cursor/skills/` + `.cursor/rules/` + локальні ключі / MCP. **Workspace UI** — список частих сценаріїв (вітрина), не заміна Agent Window. Детальніше про режим дій — у розділі Agent Window.

### Як не плутати «стіл» і «руки»
| Потрібно | ChatGPT | Claude | Cursor |
|----------|---------|--------|--------|
| Пам’ять про ваш домен | Project + файли | Project + файли | Workspace + rules/skills |
| Лише відповідь / чернетка | чат у Project | чат у Project | Ask / чат |
| Дії (браузер, кліки, «зроби») | Work / agent | Cowork | Agent Window |

Без Project/workspace навіть найрозумніша модель щоразу вигадує ваш контекст наново. Без Work/Cowork/Agent — лишаєтесь на рівні порад, а не виконання.
