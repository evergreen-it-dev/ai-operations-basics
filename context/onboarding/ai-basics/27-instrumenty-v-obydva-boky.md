# Pro: інструменти в обидва боки

Handoff Lovable ↔ Cursor (і будь-які інші) рідко ідеальний з першого разу. Подивіться → поверніться → зробіть вивід зрозумілішим для наступного інструмента. І навпаки — підкажіть Cursor, як читати дані з Lovable.

Інструменти можуть «знати» один одного частково (наприклад, ChatGPT вміє писати промпти для Lovable), але не завжди (Lovable може не знати Rules для Cursor). Немає доки — спитайте інструмент «як тобі писати?» і збережіть відповідь як MD. Погано написано — спитайте, як краще.

## Детальніше

Мета — навчений **конвеєр** із явними форматами на стиках, не один універсальний промпт на всі світи. Див. також універсальні формати й каскад.
