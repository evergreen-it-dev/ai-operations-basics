# Розділяйте «розумну роботу» і «механіку»

Те, що потребує складних рішень (архітектура, дизайн, пріоритизація) — **сильна модель** (smart / Thinking за потреби).

Механіку (рендер шаблонів, конвертації, рутина) — **скрипти / templates** і за потреби звичайна/smart модель, не «магія».

**Не плутайте механіку з Fast:** Fast без потреби часто **×1.5–×6 дорожчий** — безглузде паливо токенів. Дешевше і стабільніше винести рутину в скрипт.

## Детальніше

| Тип | Хто |
|-----|-----|
| Розумна робота | Strong / Thinking за потреби |
| Механіка | Script / template |
| Оркестрація | Agent на smart після готового skill |
| Fast | Лише свідомо, рідко, після заміру $ |
