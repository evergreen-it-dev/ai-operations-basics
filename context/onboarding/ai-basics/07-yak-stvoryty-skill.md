# Як створити перший Skill

1. Новий Agent у потрібному workspace.
2. Smoke-test інтеграції («Чи бачиш пошту / Jira / …?»).
3. Опишіть задачу людською мовою (мета, джерела, формат).
4. Нехай агент виконає **раз**.
5. «Оформи як skill» (або збережіть інструкцію вручну в `.cursor/skills/`).
6. **Новий чат** → короткий тригер → перевірка.
7. Push, якщо skill командний.

## Детальніше

### Що прописати в інструкції
- джерело даних і фільтри;
- горизонт (сьогодні / тиждень / місяць);
- куди писати результат (файл, чат, таблиця);
- що робити при помилці доступу;
- заборони (не слати клієнту / не комітити секрети без підтвердження);
- критерій «готово».

### Типові затикання
- зробили результат у чаті, **забули** зберегти skill;
- skill лише локально, колеги не бачать (немає push);
- MCP offline у новому чаті — smoke-test знову;
- тригер занадто розмитий («зроби як завжди») — агент не підхоплює потрібний skill.
