# Великі дані: скачай → збережи → аналізуй файл

Коли агент витягує великий JSON / лог / таблицю прямо в чат, контекст роздувається. Домовленість: інструмент **скачує або зберігає** артефакт у файл, а агент аналізує **файл** локально. У чат — лише summary.

Це масштабується на великі обсяги.

## Детальніше

Поєднайте з утисканням JSON і MCP Resources. Raw лишайте на диску для баг-розслідувань, не в історії чату.
