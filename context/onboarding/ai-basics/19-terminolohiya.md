# Термінологія AI

| Термін | Одне речення |
|--------|----------------|
| **Промпт** | Запит до AI звичайною мовою, не «програма». Якість промпта напряму впливає на якість результату. |
| **LLM** | Велика мовна модель — «мозок»: читає промпти, аналізує контекст, генерує відповіді. |
| **AI-агент** | Віртуальний співробітник end-to-end: отримати дані → обробити → видати результат. |
| **Skill** | Збережена повторювана інструкція (часто зі скриптами) у workspace. |
| **MCP** | Model Context Protocol — підключення моделі до файлів, API, інструментів; «розширення пам’яті». |
| **Клієнт MCP** | Програма (напр. Cursor), що дає AI доступ до MCP і вашого коду/даних. |
| **Workspace** | Репо з контекстом, rules, skills, MCP. |

## Детальніше

### Навіщо спільний словник
Без нього легко ставити задачі не тому шару: просять «агента», маючи на увазі разовий промпт; або «MCP», маючи на увазі просто файл у чаті. У команді домовтесь: що таке rule, pattern, model, example, skill.

### Промпт ≠ програма
Ви формулюєте повідомлення як людині. Не треба «синтаксису заклять» — треба ясність мети, контексту й критеріїв готовності.

### Агент vs чат
Чат відповідає. Агент **діє** (файли, MCP, браузер) і може пройти ланцюжок до результату, якщо ви дали інструменти й правила.
