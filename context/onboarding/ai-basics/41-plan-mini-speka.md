# Спочатку план і міні-спека — потім виконання

Чим менше «магії» в голові агента і чим більше перевірюваних проміжних артефактів (план, чеклист прийняття, міні-спека: вхід / вихід / шляхи), тим менше переробок після реалізації.

У Cursor: Ask/Plan для артефактів → Agent для виконання за затвердженим файлом.

## Детальніше

Міні-спека може бути короткою: мета, входи, виходи, edge cases, «коли питати людину». Без цього агент імпровізує в проді вашого процесу.
