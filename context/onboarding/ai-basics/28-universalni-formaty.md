# Універсальні формати для AI

Найкраще «їдять» моделі:
- **Markdown** — тексти й таблиці;
- **Mermaid** — схеми;
- **Event / Action у MD** — процеси.

**CSV / XLS** як єдиний носій сенсу — гірше за все для LLM.

Пам’ятайте: формати, зручні людині, часто не оптимальні для AI. Модель прочитає навіть «битий» файл без пробілів — але ви втратите контроль і повторюваність.

Код у репо = дані: можна дати завдання згенерувати гайд, документацію чи приклади використання — як миттєве рев’ю.

## Детальніше

Оптимізуйте handoff під **наступний** AI-крок, не лише під читання людиною. На стику інструментів — окремий короткий MD-контракт полів.
