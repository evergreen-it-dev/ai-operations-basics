# AI-зація процесів — база знань

Короткі статті для людей, які починають (або вже) автоматизувати операційну роботу за допомогою AI-агентів: Cursor, ChatGPT, Claude, промпти, skills, MCP, браузер, розклад.

Це практичні нотатки: як говорити з агентом, як збирати skill і як підключати системи.

> Локальна тека `context/onboarding/ai-basics/`. Сторінки компанії з Confluence сюди не пишуться: для них є `context/docs/confluence/`.

Кожна стаття: коротке **інтро** зверху → секція **«Детальніше»** знизу. Можна читати з телефону по одній — не обов’язково все підряд за раз.

---

## Як користуватися

1. Почніть з блоку **«Старт»** нижче — це фундамент.
2. Далі йдіть **по порядку оглавлення** (воно вже вибудуване логічно).
3. Коли доходите до практики — відкрийте Agent / Project і одразу пробуйте на своїй задачі.
4. Повертайтесь до окремих статей за потреби (напр. Fast, MCP, AgentOps).
