# Як покращити Skill

Після першої версії майже завжди треба **прискорити й стабілізувати**: засічіть час → оптимізуйте → прогоніть знову. Перший skill — чернетка, не фінал.

## Детальніше

### Що гальмує
- зайвий браузер замість API/MCP;
- розмиті критерії «готово»;
- суперечливі абзаци в інструкції (див. ненасичений контекст);
- великий raw JSON у чаті замість файлу / slim.

### Якщо «пливе»
1. Прочитайте файл skill самі — як код.
2. Увімкніть розумнішу модель і спитайте: «де відхилився від інструкції?»
3. Виправте **правила**, а не лише «зроби ще раз».
4. Порівняйте два прогони: що змінилось у вході / моделі / контексті.
