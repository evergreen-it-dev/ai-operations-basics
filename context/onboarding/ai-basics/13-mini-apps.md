# Mini-apps: звіт, який зручно читати

**Mini-app** — згенерований UI поверх результату агента (рішення / наступний крок), зручніший за стіну тексту в чаті.

Генерується під задачу, не окремий продукт у App Store. Мета — щоб людина **швидко вирішила**, а не перечитувала лог.

## Детальніше

### Типовий зміст
- що потребує рішення зараз;
- наступна дія;
- ризики / винятки;
- посилання на файли або чат із деталями.

Не плутайте mini-app із самим skill: skill збирає дані, mini-app — презентує їх для людини.
