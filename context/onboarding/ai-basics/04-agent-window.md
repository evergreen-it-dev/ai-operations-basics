# Agent Window: коли потрібен саме він

- **Ask / чат** — відповідає, майже нічого не змінює.
- **Agent** — діє: файли, термінал, браузер, MCP, skills.

**Agent Window** (велика синя кнопка) — для вбудованого браузера й UI-сценаріїв. Паралелі: Claude **Cowork**, ChatGPT **GPT Work**.

Без Agent Window багато «ручних» дій агента (кліки в UI, логін, скріншоти сторінки) просто недоступні.

## Детальніше

### Ask vs Agent

| | Ask | Agent |
|---|-----|--------|
| Відповіді | так | так |
| Дії в системах | майже ні | так |
| Браузер / MCP / skill | обмежено | так |
| Зміни файлів / термінал | ні / обмежено | так |

### Smoke-test
Відкрийте Agent Window → «відкрий google.com у браузері агента» → побачили керовану вкладку. Якщо вкладки немає — ви в Ask або неправильному режимі вікна.

### Коли Ask достатньо
Коротке питання, рев’ю чернетки, «поясни цей абзац» — без дій у системах. Для всього, що має *змінити* світ навколо — Agent.
