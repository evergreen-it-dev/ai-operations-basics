# API проти браузера: драбина надійності

1. **API / скрипт** — найстабільніше, найменше токенів.
2. **MCP** — зручна обгортка над API/інструментами.
3. **Браузер агента** — коли API немає; повільно, крихко, залежить від UI.
4. **Playwright / «по-старому»** — запасний контур.

Рухайтесь **вгору** драбиною, щойно зрозуміли повторюваний сценарій.

## Детальніше

### Коли браузер ок
Discovery («як виглядає екран»), рідкісний сценарій, короткостроковий fallback, логін вручну один раз.

### Компроміс
Спочатку розвідайте браузером → оформіть skill → дотисніть до API/MCP, коли сценарій стабільний. Не лишайте продакшен-процес на вічному браузері без потреби.
