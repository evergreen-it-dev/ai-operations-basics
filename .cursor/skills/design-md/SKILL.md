# DESIGN.md

Формат з [What is DESIGN.md?](https://designmd.ai/what-is-design-md): один markdown-файл, який агент читає, щоб збирати інтерфейс у тій самій системі.

Це не знімок екрана Figma. Знімок макета лишається `context/design/<figma-name>/design.md` (skill `figma`). Дизайн-система — окремий файл `DESIGN.md`.

## Куди писати

`context/design/<slug>/DESIGN.md`

`<slug>` — латиниця, kebab-case, коротко за назвою системи. У корінь цього репозиторію файл не класти. У корінь репозиторію продукту — лише якщо користувач прямо просить покласти систему туди, де її читатиме агент того продукту.

## Звідки брати факти

Спочатку локальні файли: `DESIGN.md`, якщо вже є, і знімок макета в `context/design/`. Кольори й розміри, яких немає у джерелі, не вигадувати. Немає значення — у секції один рядок, що джерело цього не дає.

Джерело може бути знімок Figma, змінні з Figma API або текст користувача. Браузер для Figma не відкривати.

## Секції

Саме в такому порядку. Порожню секцію не викидати.

1. Colors — ім’я, hex, де використовується.
2. Typography — сімейство, розмір, насиченість, коли цей стиль.
3. Spacing — базова одиниця і шкала для padding, margin, gap.
4. Components — варіант, розміри, кольори, радіус.
5. Elevation — рівні тіней і глибини.
6. Guidelines — що робити і чого не робити.

Іншу секцію додавати лише якщо вона є у джерелі.

## Шаблон

```markdown
# Назва системи

## Colors
- **Primary** (#HEX): кнопки і посилання

## Typography
- **Headline**: Family, 32px, Bold — заголовок сторінки
- **Body**: Family, 16px, Regular — основний текст

## Spacing
- **Base**: 4px
- **Scale**: 4, 8, 12, 16, 24, 32

## Components
- **Button / primary**: фон #HEX, текст #HEX, радіус 8px, padding 12px 16px

## Elevation
- **Level 1**: тінь для картки

## Guidelines
- Do: один акцентний колір на екран
- Don't: не змішувати радіуси з різних кроків шкали
```

Писати мовою джерела, якщо джерело вже якоюсь мовою. Новий файл без мови джерела — українською.

Коли далі збираєш UI цієї системи, читай цей `DESIGN.md`, а не тягни токени заново.
