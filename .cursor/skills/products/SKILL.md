# Продукти

Код і доки продукту лежать у `context/products/<product-name>/`.

Це git submodule. У теці — окремий клон репозиторію продукту, зі своїм git. Батьківський репозиторій тримає лише вказівник на коміт (`.gitmodules` і gitlink).

Subtree тут не використовуємо. Subtree вливає файли чужого репозиторію в історію цього репо, окремого клону в теці немає.

## Як додати продукт

```bash
git submodule add <url-репозиторію> context/products/<product-name>
```

Ім’я теки — латиниця, kebab-case, коротко за продуктом.

Після клону цього репозиторію підтягнути продукти:

```bash
git submodule update --init --recursive
```

## Як працювати

1. Код і доки читати в `context/products/<product-name>/`. Не копіювати їх у `context/company/` чи `tasks/`.
2. Коміт у код продукту — у репозиторії submodule. У батьківському репозиторії змінюється лише вказівник на коміт, якщо треба зафіксувати версію.
3. Факти про команду й процеси — `context/company/`. Політики компанії — `context/onboarding/`.
4. Немає теки продукту — так і сказати. Не вигадувати репозиторій і не клонувати його без явного запиту.
