# Разові задачі

Якщо запит не належить жодному конкретному skill — уся робота в одній теці:

`tasks/<task-name>/`

Ім’я теки придумай сам: латиниця, kebab-case, коротко за змістом. Приклад: `invoice-may-check`.

## Що покласти

1. `task.md` — що попросили, що зроблено, де лежать файли. Пиши його одразу, не в кінці.
2. Усе інше цієї задачі — у тій самій теці: таблиці, скрипт, вигрузка, чернетка. Окремі підпапки не розводь, якщо без них і так видно, що до чого.

Не створюй порожніх тек «на потім».

## Чого не робити

Тека `tasks/` у git не входить. У відповіді скажи це одним реченням.

Не перенось результат у `tools/`, `docs/` чи `context/`, поки людина сама не скаже, що це треба зберегти. Тоді запропонуй конкретний шлях.

Якщо задача насправді про вже наявний skill (пошта, Teams, Telegram, Jira, Confluence, голос, персони, операції) — роби її тим skill, а не новою текою в `tasks/`.
